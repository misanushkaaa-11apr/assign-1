Setup Proof (VS Code, Node.js, Live Server)

Steps:
1.VS Code Setup --> It is a code editor used to write and edit programs in different programming languages. Open VS Code and check its version under Help → About.
2.Node.js Setup --> It is a JavaScript runtime environment that allows JavaScript code to run. Open the terminal using Ctrl + ` and run to check the installed versions.
3.Live Server --> It is a VS Code extension that helps run HTML files in a web browser and automatically refreshes the page when changes are saved. Install the Live Server extension from the      Extensions panel.
* Open an HTML file and click Go Live to run it in the browser.
