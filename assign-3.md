Terminal Navigation 

Commands and Their Uses for Git:

| Command            | Task                                       |
| ------------------ | ------------------------------------------ |
| `pwd`              | Displays the current folder.               |
| `ls`               | Lists files.                               |
| `cd practice`      | enter a folder.                            |
| `rm old.html`      | Moves to the parent folder.                |
| `mkdir practice`   | Creates a folder.                          |
| `touch index.html` | Creates a empty file.                      |
| `clear`            | Clears the terminal screen.                |
| `rm -r css`        | Delete a folder.                           |
| `rm old.html`      | Delete a file.                             |
| `code.`            | Open folder in VS Code.                    |
| `clear`            | Clear the scree.                           |
| `cp index.html     | Copy a file.                               |
|  backup.html`      |                                            |
| `mv backup.html    | Rename / move a file.                      |
|  old.html`         |                                            |
| `cat index.html`   | Print file contents.                       |
